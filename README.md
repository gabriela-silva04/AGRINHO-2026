# 🌱 Agro Forte, Futuro Sustentável

Este é um projeto web escolar desenvolvido para apresentar os impactos positivos, tecnologias e inovações que unem a produtividade no campo à preservação ambiental. O site serve como uma plataforma informativa sobre a agricultura sustentável e inteligente.

## 🚀 Funcionalidades

* **Design Responsivo**: O site se adapta visualmente a diferentes tamanhos de tela (computadores e celulares).
* **Efeitos Visuais**: Cartões interativos que aumentam de tamanho (`hover`) ao passar o mouse.
* **Mensagens Dinâmicas**: Um botão interativo que sorteia e exibe frases sustentáveis e conscientes sobre o ecossistema do agronegócio.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as três tecnologias pilares do desenvolvimento web front-end:

* **HTML5**: Estruturação semântica do conteúdo da página.
* **CSS3**: Estilização moderna com o uso de layouts em Flexbox, degradês (`linear-gradient`) e transições suaves.
* **JavaScript (ES6)**: Lógica para manipulação do DOM e geração aleatória de mensagens de conscientização.

## 📁 Estrutura de Arquivos

Para o correto funcionamento do projeto, os arquivos devem estar organizados da seguinte forma:

```text
├── index.html          # Estrutura principal da página
├── style.css           # Estilização e identidade visual (design)
├── script.js           # Comportamento interativo (lógica do botão)
└── imagens/            # Pasta destinada aos arquivos de mídia
    └── agro.jpg        # Imagem de fundo utilizada no banner principal
```

## ⚙️ Como Executar o Projeto

1. Baixe todos os arquivos do repositório para o seu computador.
2. Certifique-se de manter a estrutura de pastas descrita na seção acima.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente em qualquer navegador de sua preferência (Google Chrome, Firefox, Edge, etc.).
